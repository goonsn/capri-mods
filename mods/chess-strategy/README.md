# Chess strategy

Know-how Capri follows whenever she plays chess on Chess.com, Lichess or a chess app.

- Kind: skill
- Made by: Issei
- Needs: Capri 0.8.4 or newer

It covers how to read the board and make moves, a safety check to run before every move, opening principles, three simple openings for each colour, the tactics to look for, middlegame plans, the basic endgames, managing the clock, and what to do when a game goes wrong.
