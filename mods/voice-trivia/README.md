# Voice Trivia

Multiple-choice trivia out loud, with scores.

- Kind: code mod
- Made by: Issei

| Say | She says |
|---|---|
| quiz me on anime | Question 1 of 5. Which studio made Spirited Away? A: Madhouse. B: Studio Ghibli. ... |
| B, or studio ghibli | Right! Okay, nerd. |
| hint | Fifty-fifty. It's B, Studio Ghibli, or D, Kyoto Animation. |
| stop the quiz | Quiz stopped. You got 3 out of 4. |

Questions come from [Open Trivia DB](https://opentdb.com), with her own questions as a backup when offline. Topics include anime, games, movies, music, science, history and geography. Windows only.
