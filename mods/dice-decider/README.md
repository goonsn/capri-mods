# Dice & Decider

Fair dice, coin flips, random numbers and picks.

- Kind: code mod
- Made by: Issei

| Say | She says |
|---|---|
| roll 2d6 plus 3 | Rolling 2d6 plus 3: 4 and 5, plus 3. Total 12. |
| roll with advantage | Rolling d20 with advantage: 18, dropped 9. Total 18. |
| flip a coin | Tails. |
| pick between pizza, tacos or sushi | Tacos. Final answer. |
| random order: Sam, Alex, Jo | Here's the order: Jo, then Sam, then Alex. |

Say "dice help" for the rest. Rolls use real random numbers, not her brain. Windows only.
